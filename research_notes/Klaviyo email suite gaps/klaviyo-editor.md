# Klaviyo email, SMS, and content-editor inventory (Shopify merchant)

Scope: drag-and-drop email editor, personalization, product feeds, coupons inside messages, preview/tracking, and the SMS/MMS/RCS composer. Sources are Klaviyo Help Center and the developer filter glossary unless marked. Date checked: 2026-09-24.

The suggested article `115005258568` is campaign analytics, not the editor. The current editor guide is [Guide to the email template editor](https://help.klaviyo.com/hc/en-us/articles/4407911841435) (updated Mar 18, 2026).

Official block and layout names below are only those named on that guide or the columns article. Countdown is not a native block.

## What block types exist in the drag-and-drop email editor?

### Takeaway
Klaviyo’s Basic sidebar is blocks plus layouts (Section and Columns), with a separate Universal tab. Named content blocks are Text, Image, Split, Button, Header/link bar, Drop shadow, Divider, Social link, Spacer, Product, Coupon, Table, HTML, Review quote, and Video. There is no native countdown, logo-only, or AMP block.

### Cited Findings
- Sidebar choice is “basic blocks” versus “universal content.” Layouts are “sections and columns.” Blocks and sections can be cloned, deleted, or saved from hover icons, and moved by drag. Undo/redo lasts only for the current editing session; the template autosaves; the same template open in more than one tab is not merged, and “an older version can overwrite newer edits.” — [Guide to the email template editor](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Text.** Styles are Normal or Heading 1–4 from template styles, or per-block formatting. UTF-8 “supports Latin characters, emojis, double byte characters, and more.” Dynamic content goes in the text block. RTL is a CSS snippet in source at the top of the template, not a toggle. Block styles include background color and padding. Paste from Docs/Word should be plain text (`Command+Shift+V` / `Ctrl+Shift+V`) or style tags come with the paste. Button and table text is edited in the sidebar, not on the canvas (text-block article); a 2026 editor upgrade moves table and split text to in-canvas editing. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435); [How to add and edit text blocks](https://help.klaviyo.com/hc/en-us/articles/27066187499291); [About the upgrade to text editing](https://help.klaviyo.com/hc/en-us/articles/49469198235419)
- **Image.** Sources: Image Library, Upload Image (JPEG, PNG, or GIF), Import Image by URL, Dynamic Image from an event or profile image URL. Settings: alt text, link address, width, alignment, and other styles. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Split.** Two columns, image or text only, default 50/50, width via Split settings. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435); [How to add columns](https://help.klaviyo.com/hc/en-us/articles/115000807711)
- **Button.** Requires Text and URL. Appearance: color, corner radius, padding, font, and other styles. Intended as a few CTAs, not many links. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Header/link bar.** Logo plus navigation links. “You can select different layouts for desktop and mobile.” Per-link device display; Klaviyo recommends fewer links on mobile. Font, colors, and spacing. Outlook may add a border; workaround is an image logo plus a table of links. This is the header/logo pattern; there is no separate “logo” block in the guide. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Drop shadow.** A block, not a style on other blocks. Shadow color “light, dark, and darker,” plus background color and padding. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Divider.** “Simple line.” Solid, dashed, or dotted. Color, size, and padding. “Formerly called Horizontal Rule.” — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Social link.** Icons for “Instagram, Pinterest, Facebook, X (Twitter), and more.” Full-color, or simplified black, white, or grey. Custom icons: upload images, “96px square” recommended; for alignment with Klaviyo icons, “50px wide” and centered in the file. Reorder by dragging labels. **Add Spacer** controls gaps. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Spacer.** Vertical space between stacked blocks. Side-by-side gaps use left/right padding, not the spacer. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Product.** Dynamic (product feed) or Static (hand-picked catalog items). Can show images only, or name and price. Full style list is in the block’s styles tab. Details under the product question below. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Coupon.** Drag in, click **+**, pick a coupon (search or category filter). Displays to all recipients; if a recipient has no code yet, “it will be assigned to them automatically at send time.” Same behavior as a coupon template tag, “with built-in styling.” Optional header text; coupon text style, background color, and border. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435); [How to use a coupon block](https://help.klaviyo.com/hc/en-us/articles/47691927326107)
- **Table.** Starts as one row, two columns. Table Settings adds rows and columns; widths autospace or manual. Each cell is Text or Image; switching cell type can wipe content (undo). Borders, colors, fonts in Table Settings. Also a Dynamic mode for lists (cart lines): row collection plus row alias. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435); [How to use a table block](https://help.klaviyo.com/hc/en-us/articles/32908976218779)
- **HTML.** Custom code, third-party features “like countdown timers,” or custom CSS. The guide points countdown at a separate article, so countdown is not its own block. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Review quote.** Only if you “use Klaviyo reviews.” Picks from a selection of reviews. Ineligible until there are enough “high-quality” reviews, until new reviews are processed (“wait a few hours”), or if reviews are unverified. Verified means submitted via a Klaviyo review-request flow link, or marked verified in a CSV import. “Unverified reviews, including reviews submitted directly to your site, are not eligible.” — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Video.** Not inline playback. Paste a URL from “Youtube, Vimeo, TikTok, or your video hosting platform.” YouTube can auto-pick a thumbnail; other hosts need an uploaded thumbnail. Play button is overlaid and can be toggled off. Click opens a new tab. “We don't support directly embedded video” because major clients strip it. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- **Columns** (layout, not a content block). Under Layout. 1–4 columns, preset widths only, any block type, multiple blocks stacked inside one column. — [How to add columns](https://help.klaviyo.com/hc/en-us/articles/115000807711)
- **Section** (layout). Every block sits in a section. New templates start with at least one. Drag a Section in to add another. — [How to use sections](https://help.klaviyo.com/hc/en-us/articles/4408802293019)
- Style hierarchy: template styles apply first, then section, then block. “If a block or section’s styles conflict with your template styles, the block and section styles will be used.” Template-level settings: template background, optional background image, content background, width (“600px recommended”), corner radius, margins, padding, border; text and four heading styles; font, letter spacing, line spacing, alignment; Mobile optimization toggle; Currency if different from the account. New templates can inherit Brand Library > Brand. Color picker: gradient, HEX or RGB, recent/template colors, eyedropper. Eyedropper is “not currently available for text, split, or table blocks.” — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- Most blocks have Styles plus Display Options. Display options are the same across blocks; style controls differ. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- 2026 text-editor upgrade: new templates use the upgraded editor for text, table, and split. Source code view in those three “is being replaced by the new Django Tag Builder,” with a dedicated HTML block for raw code. Complex blocks (tables, custom styling, embedded style tags) are not auto-converted; Klaviyo shows a side-by-side of upgraded versus preserved-as-HTML and the user chooses. Incompatible blocks “will convert to HTML blocks.” Clones keep the original’s editor. — [About the upgrade to text editing](https://help.klaviyo.com/hc/en-us/articles/49469198235419) (updated Apr 21, 2026)
- Related, not separate blocks: hybrid HTML templates can still use product blocks and universal content; custom HTML can be imported; drag-and-drop HTML can be exported. Those articles are linked from the editor guide and the templates help index. — [Editor guide additional resources via templates section index](https://help.klaviyo.com/hc/en-us/sections/14543554717467)
- The templates help index also lists articles titled “Comment on emails in the drag-and-drop editor,” “How to add custom fonts,” and “How to edit the plain text version of an HTML email.” Those articles were not opened, so their controls are not inventoried here. — [Templates section](https://help.klaviyo.com/hc/en-us/sections/14543554717467)

### Inferences
- A gap analysis should treat Split, Columns, and Table as three different column systems, not one “columns” feature. Table is the only one that stays side-by-side on mobile.
- Review quote, coupon, and product are the commerce-specific blocks. Everything else is layout, media, or code.
- “Drop shadow” and “header/link bar” are easy to miss if a competitor inventory only lists text, image, button, divider, spacer, social, HTML.

### Gaps
- No official page opened here lists the Basic sidebar in one screenshot with every icon label. The inventory is the prose list in the Mar 18, 2026 editor guide. A block added after that date and not mentioned in later articles (coupon block article Mar 16, 2026; product feeds Aug 11, 2026) would be missed.
- Per-block style matrices (every padding/border/radius control on Button vs Product vs Social) are not fully copied; the guide says to scroll each block’s styles tab.
- Commenting, custom fonts, and the plain-text part editor were not opened.
- Countdown timer vendor options inside the HTML-block article (`115000780232`) were not opened. Only the fact that countdown is a third-party/HTML feature, not a native block, is confirmed.

## How do sections, columns, mobile stacking, padding, and show/hide work?

### Takeaway
Sections group blocks and carry background, border, padding, column stacking, device visibility, show/hide logic, and content repeat. Columns and Split stack on mobile; tables do not, but a table column can be changed or hidden for mobile. Show/hide is per block or per section, by device and by profile or trigger-event rules. Section rules and block rules can cancel each other out.

### Cited Findings
- “Every block must be contained within a section.” Blocks can be dragged between sections. Delete via trash; save via the star icon into saved/universal content. — [How to use sections](https://help.klaviyo.com/hc/en-us/articles/4408802293019)
- Section Styles: background images; content color **auto** (template color), **manual**, or **none** (transparent); border solid, dashed, or dotted; padding “between your content blocks and the edge of a section”; alignment that includes “whether columns should stack on mobile” and whether column content aligns top, center, or bottom. — [How to use sections](https://help.klaviyo.com/hc/en-us/articles/4408802293019)
- Clicking beside a section’s content opens the section. Clicking a block opens the block. Section styles apply after template styles and before block styles. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- Device visibility: Display options choose desktop, mobile, or both. Section-level “Set same visibility for all blocks in this section,” then Desktop or Mobile. A desktop-only block’s edits “will not impact the mobile version of the email, and vice versa.” — [Understanding display options](https://help.klaviyo.com/hc/en-us/articles/4408802299547); [How to use sections](https://help.klaviyo.com/hc/en-us/articles/4408802293019)
- Template Styles > Mobile: enable mobile optimization (recommended) or “display the same styles and content on both desktop and mobile.” — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- Side-by-side comparison, official table: Split = 2 columns, precise widths, image or text only, stacks on mobile. Columns = 1–4, limited widths, any block (example given: text, image, review quote), stacks on mobile. Table = any number of columns, manual width, image or text only, does not stack. “Tables can be challenging for accessibility, as screen readers have a hard time parsing them.” Columns stack “with the left side stacking on top of the right.” To keep columns side-by-side, use a table. Table column tab can “change or hide a column for mobile.” — [How to add columns](https://help.klaviyo.com/hc/en-us/articles/115000807711)
- Header/link bar is a second mobile-layout control: different layouts per device, and per-link show/hide by device. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- Show/hide logic: blocks and sections can be limited to recipients who meet criteria. Logic builder: Display tab > Use logic builder; one criterion or several with AND or OR. Custom code is the alternative (`Use code` / if-else). Event conditions can only use the flow’s trigger event. Profile and event property names are case-sensitive. If a section’s rule and a block’s rule conflict, “the block will be hidden for all recipients” (example: section = Canada, block = Massachusetts). — [How to show or hide template blocks](https://help.klaviyo.com/hc/en-us/articles/7655965301531); [Conditional logic reference](https://help.klaviyo.com/hc/en-us/articles/7655926841499); [How to use sections](https://help.klaviyo.com/hc/en-us/articles/4408802293019)
- Show/hide condition shapes documented: property is set; `not` property (missing, empty, or boolean false); `==`, `!=`, `>`, `>=`, `<`, `<=`; list membership with `in`. Booleans should be numeric unless stored as text. Combine with `and`. — [Conditional logic reference](https://help.klaviyo.com/hc/en-us/articles/7655926841499)
- Content repeat: blocks and sections can repeat from profile or event list data (abandoned-cart style). — [Understanding display options](https://help.klaviyo.com/hc/en-us/articles/4408802299547); [How to use sections](https://help.klaviyo.com/hc/en-us/articles/4408802293019)
- Padding locations that were explicitly named: template margins/padding/border; section padding; text-block padding; button padding; drop-shadow padding; divider padding; spacer block; table “padding, or spacing, around the columns”; left/right padding for side-by-side gaps. — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435); [How to use sections](https://help.klaviyo.com/hc/en-us/articles/4408802293019); [How to add columns](https://help.klaviyo.com/hc/en-us/articles/115000807711)

### Inferences
- Mobile is three separate systems: (1) template mobile-optimization on/off, (2) stack vs don’t-stack for columns, (3) show/hide entire blocks by device. A smaller suite that only has “stack columns” does not match Klaviyo.
- Desktop-only and mobile-only are alternate content, and edits do not sync between them. That is stronger than a single responsive layout.
- Conflict behavior (section AND block rules can hide a block from everyone) is a support footgun a smaller suite might not copy.

### Gaps
- The content-repeat setup article (`4408802445339`) was not opened, so repeat limits, alias syntax, and whether repeat works on every block type are unconfirmed beyond “blocks and sections” and the cart-list example.
- Exact column-width presets in the Columns modal were not listed in text.
- Whether the section “stack on mobile” control overrides the columns article’s “will stack” statement was not tested; both statements are on official pages.
- No pixel-level padding defaults were published in the pages opened.

## What personalization, event data, catalog lookups, and conditional logic exist?

### Takeaway
Tags are Django-style, case-sensitive, and work in email (including subject), SMS/MMS, push, and Customer Hub. Families confirmed: profile (built-in and custom), event (including nested), organization, links (unsubscribe, preferences, web view, preview text), dates, currency, catalog lookup, coupons, and custom objects. Conditionals are `{% if/elif/else %}`, `{% for %}`, show/hide on blocks, a no-code logic builder inside text/table/split, and content repeat. The editor also ships a large filter list (`default`, `lookup`, `floatformat`, and many more).

### Cited Findings
- “Personalization tags can be used in emails (including the email’s subject line), SMS/MMS messages, push notifications, and Customer Hub.” They were “previously called template tags.” Profile tags generally start with `person` except specials like `first_name`. Event tags start with `event` and only work in flows triggered by that event. Organization tags start with `organization`. All tags are case-sensitive. — [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731) (updated Mar 30, 2026)
- Built-in profile tags named on that page: `{{ email }}`, `{{ first_name }}`, `{{ last_name }}`, `{{ person.organization }}`, `{{ person|lookup:"$address1" }}`, `{{ person.id }}`, latitude, longitude, `{{ person.KlaviyoID }}`, `{{ person.full_name }}`, `{{ person.title }}`, `{{ person.phone_number }}`, address 2, `{{ person.City }}`, `{{ person.Region }}`, `{{ person.Country }}`, `{{ person.Zipcode }}`, `$source`, `$consent`, consent form id/version, `$consent_method`, `$timezone`, `$consent_timestamp`, `$phone_number_region`, `{{ person.ViewedItems }}` (“Recently viewed items”), `{{ person|lookup:"Expected Date Of Next Order" }}`. — [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731)
- Custom profile: `{{ person.property_name }}` or `{{ person|lookup:'property name' }}` when the name has spaces or special characters. Event: `{{ event.property_name }}`, lookup form, dotted nested `{{ event.extra.checkout_url }}`, and chained lookup when any segment has spaces or `$`. “If one property name uses lookup notation, all later properties must also use lookup notation.” — [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731)
- Organization, from Settings > Organization > Contact Information: `organization.name`, `url`, `full_address`, `street_address`, `street_address2`, `city`, `region`, `zip_code`. — [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731)
- Email-only link tags: `{% unsubscribe %}` (default word “Unsubscribe,” or custom text in quotes); `{% unsubscribe_link %}` (URL only, for a button, image, or different color); `{% manage_preferences %}` and `{% manage_preferences_link %}`; `{% web_view %}`, `{% web_view 'Open in your browser' %}`, `{% web_view_link %}`. Preview text in the body: `{% render_variable preview_text %}`. Clicking these from a preview goes to a placeholder, not a live page. List-specific preference pages are used when sending to one list; a general page is used for segments, multi-list sends, and non-list flows. Unsubscribe click goes to a customizable confirmation page. Klaviyo “requires an unsubscribe link in all emails.” — [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731); [How to add an unsubscribe link](https://help.klaviyo.com/hc/en-us/articles/115006054267)
- Date: `{% today "%Y-%m-%d" as today %} {{ today }}`. “Using the `{{ today }}` tag without the preceding code will not render anything.” Date is the account timezone and is the send time. A separate date-formatting article is linked and was not opened. — [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731)
- Currency: `{% currency_format event|lookup:"$value" %}`. Account default is Settings > Organization > Organization language and regional format. Per-template override is Styles > Currency. The tag “is only supported for variables that are numbers”; a value that already contains `$` is a string and will not format. — [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731); currency also appears as a template style in the [editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- If/else in text: `{% if %}`, unlimited `{% elif %}`, at most one `{% else %}`, `{% endif %}`. “Each email recipient will only see the first message they qualify for.” For loops: `{% for item in event.shopping_cart_items %} ... {% endfor %}` with a row alias. These tags, plus `{% with %}` / `{% endwith %}`, “do not appear in the inline text editor” but remain in the block. Edit them with the Django Tag Builder or an HTML block. — [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731)
- Logic builder (no code), updated Aug 31, 2026: if/else on profile or custom properties, for-loops over a list, and a “Configurable tag” for Django not covered by those builders (`with`, catalog). Insert from the toolbar inside a text, table, or split block. Opening tag name plus code; **Add branch** for another section. — [How to add conditional logic using the logic builder](https://help.klaviyo.com/hc/en-us/articles/55241564267547)
- Catalog lookup (separate article, not fully re-fetched; search extract of the official page): `{% catalog itemID unpublished="cancel" %}` … `{% endcatalog %}`. `itemID` is the catalog Product ID, not the SKU. `unpublished="cancel"` skips the message for unpublished items. Inside the tag, fields such as `{{ catalog_item.description }}` and `{{ catalog_item.url }}`. `has_category` checks full or partial category name and can wrap an if/else. — [Catalog lookup tag reference](https://help.klaviyo.com/hc/en-us/articles/360004785571)
- Dynamic table (event lists such as checkout line items): set the block to Dynamic, Row collection = the list path before the index (example `event.extra.line_items`), Row alias = `item`, then `{{ item.imageURL }}`. Also usable with a web feed or a profile property that is a list. Common use is abandoned-cart lines. — [How to use a table block](https://help.klaviyo.com/hc/en-us/articles/32908976218779)
- Web feeds are not product feeds. They live at Settings > Other > Web Feeds. — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- Custom objects in templates: `{{ object.object_property }}` only when an object triggered the flow; `object_filter` for one record or a count; `{% customobject %}` by id; `{% customobjects %}` to loop a profile’s records. Show/hide can use object properties. Objects must be created first. — [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731); [How to use custom objects in templates](https://help.klaviyo.com/hc/en-us/articles/35146367972763)
- Filters: “Klaviyo’s email and SMS editors support most built-in Django filters, in addition to a small number of custom filters.” Names on the developer glossary as fetched (page ended at `weeks_since`; a longer tail is unconfirmed): `abs`, `append`, `at_least`, `at_most`, `base64_decode`, `base64_encode`, `base64_url_safe_decode`, `base64_url_safe_encode`, `capitalize` (alias `capfirst`), `ceil`, `compact`, `concat`, `count`, `datetime_from_string`, `default`, `dictfilter`, `divide`, `downcase` (alias `lower`), `escape`, `escape_once`, `find_replace` (alias `replace`), `floatadd`, `floatformat`, `floatsub`, `floor`, `format_date_string`, `gt`, `gte`, `httpize`, `httpsize`, `join`, `length`, `list_to_string`, `list_where`, `lookup`, `lstrip`, `lt`, `lte`, `map`, `md5_hash`, `minus`, `missing_image`, `missing_product_image`, `modulo` (alias `remainder`), `multiply`, `newline_to_br` (alias `linebreaksbr`), `percentize`, `plus`, `prepend`, `remainder`, `remove`, `remove_first`, `remove_last`, `replace`, `replace_first`, `replace_last`, `resplit`, `reverse`, `round`, `round_down`, `round_up`, `rstrip`, `sha_1`, `sha_256`, `size`, `slice`, `sort`, `sort_natural`, `split`, `strip`, `strip_html` (alias `striptags`), `strip_newlines`, `sum_list`, `title`, `trim_slash`, `truncate`, `uniq`, `upcase` (alias `upper`), `upper`, `urldecode`, `urldecodeplus`, `urlencode`, `urlencodeplus`, `weeks_since`. — [Django filter glossary](https://developers.klaviyo.com/en/docs/glossary_of_variable_filters)
- Preview modal is “your source of truth for personalization options.” From Content > Templates you can toggle profile vs event and pick a profile or event. Campaigns: profile only; “event data is not supported.” Flows: both. — [How to use the preview panel](https://help.klaviyo.com/hc/en-us/articles/27843522951707)
- First name in subject and body is supported for email, SMS, and push, in campaigns and flows. — [How to add columns, additional resources linking the first-name article](https://help.klaviyo.com/hc/en-us/articles/115000807711)

### Inferences
- `person.ViewedItems` is a raw recently-viewed tag, separate from the product-feed “recently viewed” recommender. A smaller suite can ship one without the other.
- Catalog lookup is how a flow email renders one known product (back-in-stock, price drop, order line) when a product block feed is the wrong tool.
- The logic builder (Aug 2026) plus the Django Tag Builder means merchants are being steered off raw source view in text/table/split. HTML block remains the escape hatch.
- Custom objects and “Expected Date Of Next Order” are data-platform features exposed as tags, not editor blocks. Plan gating was not confirmed on these pages.

- Date-format tokens beyond the `%Y-%m-%d` example were not opened (`115005257788`).

- The glossary fetch stopped at `weeks_since`. Filters after that, if any, are unconfirmed.

## What product blocks and recommendation types exist?

### Takeaway
One Product block, two modes: Static (hand-picked, up to nine, does not retarget or auto-update) and Dynamic (a saved product feed). Feeds are rules, not separate blocks. Confirmed selectors include recently viewed, added to cart, “products a customer may also like,” best-selling (3-day or 90-day window), and newest products, plus category/price/stock filters. Price drop, back in stock, and low inventory are flow triggers, not product-block types. Cross-sell is the “may also like” recommender, not its own block.

### Cited Findings
- Product block is only in the drag-and-drop and hybrid editors. Custom HTML needs a hybrid template to use one. — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787) (updated Aug 11, 2026)
- Dynamic: “based on business trends (e.g., best-sellers in the last 90 days) or customized to each recipient based on what Klaviyo predicts they will be most interested in.” Static: “a set list of items that you select,” up to nine, reorder by dragging. Static item details “will not update dynamically at send time” on a flow email or a scheduled campaign, even if the site product changes. For Magento and Shopify, out-of-stock products are hidden from the catalog “so it won't appear in any feed.” — [How to add a product block](https://help.klaviyo.com/hc/en-us/articles/115000219092) (updated Mar 10, 2026)
- Block display options: title, price, customizable button; all off = image only. Layout is rows × items per row (example: 2×3 = 6). Styles include font, color, and “Original price for sale products” (strike-through next to the sale price). Strike-through “is only available for customers using Shopify, BigCommerce, WooCommerce, and PrestaShop.” Static products can be chosen with a language and region so localized title, price, and URL are used. — [How to add a product block](https://help.klaviyo.com/hc/en-us/articles/115000219092); [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- A feed is “a rule-based set of products.” Include/exclude by category, price, stock, and engagement (views, purchases, added to cart). Built under Content > Products > Product feed. Feed names: no spaces, no special characters, must not start with `_`. Multiple catalogs: pick one. — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- Dropdown is grouped as **Classic** or **Personalized for each customer**. Named in the help article: “Products a customer has recently viewed” and “Products a customer has added to cart” (both look back 90 days); “Product customers may also like” (can be informed by view or purchase history); “Best-selling products” with a window of the last 3 days or the last 90 days. Personalized feeds require a non-personalized fallback: “If the customer has limited history, what should they view instead?” — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- “What happened to trending?” The old trending option “is now expressed as a look back window of 3 days.” “Any option that uses ‘over the past 3 days’ will be a version of the old Trending order.” — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- Best-selling = count sold, “more weight given to more recent purchases.” Purchase price is not part of the rank. “Products a customer may also like” “uses AI” and “collaborative filtering” from what they ordered and similarity to other customers. It “may include products someone has viewed” but “doesn't exclusively show these products.” Recently viewed weighs recency and frequency, not recency alone. Newest products sorts on Klaviyo’s own `created_at`, not the store’s publish date, and “will not be prioritized … just because they’ve been updated or have recently come back in stock.” — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- Cart recommendations use Added to Cart if that metric exists, otherwise Checkout Started. Added to Cart is manual for Shopify and BigCommerce. View-based recommendations require Viewed Product tracking. — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- Feeds never show: items with no image, items that recipient already purchased, out-of-stock items, items that are in the flow trigger event. — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- Filters: category includes/excludes, one or many categories, match **any of** (OR) or **all of** (AND). Stock level min/max. Price min/max. Multiple filters via Add filter. Price and inventory filters are supported for Shopify, BigCommerce, and Magento 2, and for variants in custom catalogs. Filters apply to variants, but the block renders the parent item, so a shown image/price can be a variant outside the filter. Currency is whatever the catalog stored. — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- Fallback to the secondary recommender (examples given: best-selling or most viewed) happens when the person lacks data, the feed is new (“2 days to a week” to train), or Viewed/Ordered events are newer than the last training (models train “once every 2–7 days”). — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- Catalog caps: 250,000 items, 500,000 variants, 2,500 categories. Feeds do not support OAuth. Default integrations include Shopify, WooCommerce, BigCommerce, Magento 1 and 2, PrestaShop, Salesforce Commerce Cloud, Spree, Square, Wix, Mi9, Shift4Shop. Others use a custom catalog feed or API. WooCommerce “published” follows `stock_status`, not WordPress post status. — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- Shopify product feeds are available by default with the Shopify integration; they are not described as a Reviews or Marketing Analytics add-on. — [How to use product feeds](https://help.klaviyo.com/hc/en-us/articles/115005082787)
- Price drop is a flow trigger: an item someone viewed or started checkout with drops by a set amount or percent. Not sent if they already bought it, inventory is 0 or negative, or the variant is unpublished. Platforms include Shopify. — [How to create a price drop flow](https://help.klaviyo.com/hc/en-us/articles/4404249033755); [Understanding flow triggers](https://help.klaviyo.com/hc/en-us/articles/115002779051)
- Back in stock is a flow on the metric “Subscribed to Back in Stock,” plus a Back in stock delay until that item is restocked. It is not a product-feed algorithm. Shopify is supported. SMS can be added; product name in the SMS uses an event variable, not a product block. — [How to build a back in stock flow](https://help.klaviyo.com/hc/en-us/articles/115003872251); [How to use SMS in back in stock flows](https://help.klaviyo.com/hc/en-us/articles/7954040204827)
- Low inventory is another flow trigger (viewed or started checkout, stock at or below a threshold for a variant or the whole product). Not a product block. — [Understanding flow triggers](https://help.klaviyo.com/hc/en-us/articles/115002779051)
- A June 3, 2026 Klaviyo blog says you can “add a product feed block to a text message” and names feed types “like trending, recently viewed, new arrivals, or category-specific.” This is a marketing blog, not a help-center composer article. Help-center confirmation of an SMS product-feed block was not found in the SMS articles opened. — [Personalized Product Recommendations (blog)](https://www.klaviyo.com/blog/personalized-product-recommendations-in-sms-and-rcs)

### Inferences
- For a Shopify gap analysis, “product block” should be scored as: static merchandising, dynamic feed with classic vs personalized algorithms, sale-price strike-through, and locale-specific static picks. Price-drop and back-in-stock belong on the flows checklist, with catalog/event tags as the content mechanism.
- “May also like” is the cross-sell. There is no block named cross-sell.
- Excluding the trigger item and already-purchased items means an abandoned-cart email that should show the cart must use a dynamic table (or catalog tags), not a product feed. The feed is for recommendations around that event.

### Gaps
- The help article does not print the full Classic dropdown. “Most viewed” appears only as a fallback example, not as a confirmed menu label. Other classic labels (for example an explicit “most viewed products” row) are unconfirmed.
- The second dropdown under “may also like” (Viewed Product vs Ordered Product vs both vs custom metric) is described in a community post, not in the help article text that was fetched. Treat that four-way split as unconfirmed on help.klaviyo.com. — community post was [Understanding the new product feeds experience](https://community.klaviyo.com/product-updates-announcements-51/understanding-the-new-product-feeds-experience-5685); do not treat it as the product spec.
- Whether product feeds can be placed in SMS/RCS inside the product UI is unconfirmed on the help center (blog only).
- Recommendation model quality, training data requirements, and any plan paywall for “personalized” vs “classic” were not stated. The article says feeds are part of normal product tools for Shopify.
- Per-item button text defaults, image aspect-ratio crop, and max products in a dynamic block (rows × columns cap) were not given as hard limits. Static cap of nine is confirmed.

## What coupon and unique-code features exist inside emails and flows?

### Takeaway
Shopify merchants can generate unique (single-use) codes in Klaviyo or use one static code. In email, insert them with a Coupon block or `{% coupon_code 'CouponName' %}`. Unique codes also work in campaigns, flow emails, and SMS. Email allows multiple coupons per message; SMS allows one. Hidden show/hide blocks can still mint codes for people who never see them. A link can apply the code to the Shopify cart. Customer Hub can show the same coupons on-site; that is a separate product.

### Cited Findings
- Two types: static (one shared code, example Welcome20) and unique/dynamic (one code per recipient, single use). Codes can be used in emails, SMS, and sign-up forms, “as well as display them as barcodes for in-store use.” — [Getting started with coupon codes](https://help.klaviyo.com/hc/en-us/articles/115005084727) (updated Mar 17, 2026)
- Coupon block: drag from Content, **+**, select an unexpired coupon that still has codes. “The selected coupon code will display to all recipients of the email” in the block article’s “same offer” wording, while the editor guide says unassigned recipients are assigned a code at send time, “the same as inserting a coupon using a template tag.” Read together: one coupon definition for the send; unique coupons still assign per recipient at send. Styles: text, colors, layout, optional header. — [How to use a coupon block](https://help.klaviyo.com/hc/en-us/articles/47691927326107); [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- Tag path: Personalization menu > Coupons > pick the coupon. Tag form shown for Magento, and used the same way elsewhere: `{% coupon_code 'CouponName' %}`. If a field has no Personalization menu (button block), paste the tag from a text block. — [Getting started with coupon codes](https://help.klaviyo.com/hc/en-us/articles/115005084727)
- “If a coupon is included in a block that is hidden with show/hide logic, codes will still be generated.” Email can include multiple codes. “Only 1 code per SMS.” Hidden blocks can show different coupons by location or behavior, but “codes may be assigned to all recipients (even if they end up hidden)” and the send can be blocked if inventory is short. — [Getting started with coupon codes](https://help.klaviyo.com/hc/en-us/articles/115005084727)
- Shopify unique codes: usable in email campaigns, flow emails, and SMS. Discount types called out on the signup-form path (and the same coupon object): fixed amount, percentage, or free shipping; optional prefix. Codes are created in Klaviyo and show up in Shopify only after a code is generated, via Shopify’s Bulk Discounts API; the Shopify discount is tagged “App.” You cannot search Shopify for a specific unique code string; search the discount name. — [How to create unique coupon codes for Shopify](https://help.klaviyo.com/hc/en-us/articles/115006155388) (updated Mar 29, 2026); [Where to find a unique code in Shopify](https://help.klaviyo.com/hc/en-us/articles/360027468892)
- Same coupon tag in multiple flow messages gives that person the same code again (stated on the WooCommerce article; Shopify “same coupon” behavior for an SMS plus email is stated on the SMS coupon article: “if an SMS and an email include the same 20% off coupon, the coupon code will be the same”). — [How to use unique coupon codes in SMS and MMS](https://help.klaviyo.com/hc/en-us/articles/360044863132)
- SMS coupon practice: generate or upload at least 50 extra codes; leave at least 5 extra characters so the code does not add a second SMS segment; tag is `{% coupon_code 'CouponName' %}`. Klaviyo can generate codes for Shopify (also Magento 1 and 2). Uploaded codes are the path for other platforms. — [How to use unique coupon codes in SMS and MMS](https://help.klaviyo.com/hc/en-us/articles/360044863132)
- There is a help article “How to add a link that applies a coupon code to a Shopify cart” for email or SMS. The steps were not opened. — [Coupons help section](https://help.klaviyo.com/hc/en-us/sections/14544782046619)
- Signup forms have their own coupon block (static, uploaded unique, or Shopify unique). Out of scope for the email editor except that the same Shopify coupon can be created there. Shopify unique form coupons “will be automatically applied to a customer’s cart at checkout” when the form is completed. — [How to add coupon codes to sign-up forms](https://help.klaviyo.com/hc/en-us/articles/6038674938523)
- Customer Hub (on-site, not the email editor) shows unique coupons a profile already received, and static Shopify codes if added manually. — [How to set up coupons for Customer Hub](https://help.klaviyo.com/hc/en-us/articles/39273771656987)
- Contrast, not Shopify: WooCommerce unique codes are “flow emails only, not campaign emails.” Magento 1 dynamic codes are “not currently available when sending campaign emails.” Shopify does not have that campaign restriction in the Shopify article. — [WooCommerce unique coupons](https://help.klaviyo.com/hc/en-us/articles/22168739689627); [Magento 1 coupons](https://help.klaviyo.com/hc/en-us/articles/115005246547)

### Inferences
- The merchant-facing Shopify set is: static code, unique code minted at send, coupon block or tag, multiple codes per email, one per SMS, cart deep link, and form/hub distribution of the same codes.
- Show/hide is not a safe way to branch offers unless code inventory covers every recipient, because hidden coupons still allocate.
- Barcode display is claimed on the getting-started page; the exact block or tag used to render a barcode was not opened, so treat “barcode” as a documented capability without a confirmed UI control.

### Gaps
- Shopify coupon rule matrix (minimum spend, applies-to collection, usage limit, expiry, prefix format, code length) was not copied from the create-coupon screen.
- The Shopify cart-link article was not opened, so the URL pattern is unconfirmed.
- How the coupon block chooses between showing one static string vs a per-recipient unique string is inferred from the two articles above, not demonstrated with a screenshot.
- Barcode rendering steps: unconfirmed.
- Uploaded-code CSV format: not opened.

## What preview, inbox-client preview, dark mode, AMP, link tracking, UTM, and unsubscribe features exist?

### Takeaway
Preview & test renders a real profile or, in flows and the template library, an event. Paid accounts can run inbox tests, including a Dark mode group, and share a link that expires in 6 days. Klaviyo does not apply dark mode itself. AMP is a separate pasted-code version, not a drag-and-drop block, and needs an approved setup. Clicks are rewritten through Klaviyo. UTM can be appended automatically on email and SMS. Unsubscribe is required and uses the tags in the personalization section.

### Cited Findings
- **Preview & test** is the in-editor preview “in a recipient’s inbox.” For campaigns, list- or segment-triggered flows, price-drop flows, and date-triggered flows: search a profile. For metric-triggered flows: set Preview data source to Event and pick the triggering event; a different event or profile-only preview “may not render correctly.” — [Editor guide](https://help.klaviyo.com/hc/en-us/articles/4407911841435)
- Preview data rules: templates can toggle profile or event; campaigns are profile-only; flows support both. Change profile via Search profiles. — [Preview panel](https://help.klaviyo.com/hc/en-us/articles/27843522951707)
- Inbox preview text is a field on the email setup screen. Klaviyo “automatically adds spacers” so only that text shows in the inbox. Character count varies by client. To show it in the body, `{% render_variable preview_text %}`. To blank the inbox snippet, an HTML block at the very top with a hidden spacer snippet (the article supplies the markup; not copied here). — [How to insert preview text](https://help.klaviyo.com/hc/en-us/articles/115005082687)
- **Inbox testing:** from the template editor, Preview & test > Inbox testing. Pick one or more inboxes. “There is a limit on the number of previews you can generate each month.” Options are grouped; one group is **Dark mode**. “This feature is only available for paid Klaviyo accounts.” Share a preview link; the link “will expire after 6 days.” — [How to use inbox testing](https://help.klaviyo.com/hc/en-us/articles/37463094051611)
- **Dark mode** is a device setting. “Klaviyo cannot control how dark mode is implemented.” Some clients change little unless you add dark-mode metatags (Apple Mail desktop is the example of minimal changes). Others invert colors. The article points developers at `@media (prefers-color-scheme: dark)` and `[data-ogsc]` in custom CSS. Inbox testing is the preview path; there is no “design in dark mode” toggle described as a first-class editor mode. — [Dark mode email design](https://help.klaviyo.com/hc/en-us/articles/360049181631); [Inbox testing](https://help.klaviyo.com/hc/en-us/articles/37463094051611)
- **AMP:** not part of the drag-and-drop canvas. On a campaign, Content > Add AMP Version. On a saved template, three dots > Create AMP Version. “Paste in your code and preview.” Dedicated click-tracking domains need SSL “before your AMP application can be approved.” Shared Klaviyo tracking domains already have SSL. Klaviyo “cannot help design your AMP emails or troubleshoot errors.” After send, filter Opened Email or Clicked Email by Mimetype equals AMP. In-email AMP interactions (carousel clicks that do not leave the message) “are not currently tracked.” — [Send AMP emails in Klaviyo](https://help.klaviyo.com/hc/en-us/articles/360035002831)
- **Click tracking:** links are rewritten through Klaviyo; a click records “Clicked Email,” then redirects. Can be turned off for the account (Settings > Email > Tracking > clear Track email clicks), for a recipient, or for one link. Disabling tracking does not stop the link from working, does not affect unsubscribe links, and does not change marketing consent. Changes apply to future clicks on mail already delivered. Recipient status: Subscribed and Never Subscribed are tracked; Unsubscribed is not. — [How to manage click tracking](https://help.klaviyo.com/hc/en-us/articles/55300524901787)
- Link Activity on a sent campaign: who clicked, how often, top 25 links, total and unique clicks, for email, SMS, and WhatsApp. Two elements with the same URL are not separated unless you add your own query parameters. — [Understanding available campaign analytics](https://help.klaviyo.com/hc/en-us/articles/115005258568)
- **UTM:** parameters on links for Google Analytics and similar. `utm_source` and `utm_medium` are “always turned on.” Optional: `utm_campaign`, `utm_id`, `utm_term`. Global defaults: Settings > Other > UTM tracking, plus “Automatically add UTM parameters to links.” As of June 2, 2025, default `utm_medium` changed from campaign/flow to Message type (`email`, `sms`, `push`) unless the account had already saved custom values. Per flow message: Enable UTM Tracking (email, text, WhatsApp, push). Per campaign: Include tracking parameters on the recipients step. Links need `http://` or `https://`. For SMS, “Automatically shorten links” must stay on or UTM will not be applied. Campaign analytics show the UTM values that were campaign-level settings, not hand-edited parameters. “Automatic UTM tracking is only available for email and SMS campaigns” in that analytics article’s wording; the how-to article also covers flows, WhatsApp, and push. Both are official; the analytics sentence is the narrower one. — [Understanding UTM tracking](https://help.klaviyo.com/hc/en-us/articles/115005247808); [How to add UTM tracking](https://help.klaviyo.com/hc/en-us/articles/360053921252); [Campaign analytics](https://help.klaviyo.com/hc/en-us/articles/115005258568)
- **Unsubscribe:** required. Insert via Personalization > Links and preview > Unsubscribe, or the tags above. Confirmation page. Custom link text and URL-only tag. — [How to add an unsubscribe link](https://help.klaviyo.com/hc/en-us/articles/115006054267); [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731)
- Test sends exist as part of “preview and send test emails”; the test-send article was not opened. The templates section lists it. — [Getting started with templates section](https://help.klaviyo.com/hc/en-us/sections/14543205988635)

### Inferences
- A smaller suite matching Klaviyo’s preview story needs: profile merge preview, event merge preview, inbox-client screenshots including dark mode, and a share link. Dark-mode authoring is still custom CSS, not a visual theme.
- AMP is an expert/HTML add-on path with an approval step, not a merchant block. Safe to treat as out of a basic Shopify email suite unless the suite already has custom HTML.
- UTM and click tracking are account-level defaults plus per-message toggles, not block settings. SMS UTM depends on the shortener.

### Gaps
- The inbox-test client list (which Gmail, Outlook, Apple Mail versions, and which dark-mode variants) was not copied. Only the existence of selectable inboxes and a Dark mode group is confirmed.
- Monthly inbox-test quota number: “a limit” exists; the number was not stated.
- Test-send recipient limits and whether dynamic coupons mint during a test were not opened.
- Per-link click-tracking disable UI was not walked.
- The conflict between “automatic UTM only for email and SMS campaigns” (analytics article, updated Feb 2026) and flow/WhatsApp/push UTM (how-to, updated Jan 2026) is unresolved. Both pages are live. Likely the analytics sentence means reporting of automatic UTMs on the campaign page, not that flows cannot append UTMs.
- AMP approval criteria beyond dedicated-domain SSL were not extracted.

## What does the SMS and MMS composer support, including RCS?

### Takeaway
SMS is a text composer, not a block editor. It supports personalization tags, one Klaviyo-shortened link (required for click and revenue tracking), optional branded domains on paid SMS, and one coupon tag. Adding an image, GIF, dynamic image, or virtual contact card turns the message into MMS (US, Canada, Australia only; 600 KB; PNG/JPEG/GIF). RCS is shipped as an optional per-country agent: rich cards, buttons, and media where the agent is active, with SMS/MMS fallback. RCS does not send MMS contact cards. Location sharing and payments are documented as not yet supported in Klaviyo.

### Cited Findings
- Composer is message content plus settings, not email blocks. Include a link and use Klaviyo’s shortener or “Klaviyo won't be able to track” clicks. “You must use the Klaviyo link shortener for revenue to be attributed to SMS.” Organization prefix can be prepended from account settings. Canada: a company-info link is added for Canadian recipients only. Quiet hours guidance on the same page: don’t send before 9 a.m. or after 8 p.m. recipient local time. — [Guide to crafting SMS and MMS](https://help.klaviyo.com/hc/en-us/articles/360035661191); [How to add an SMS action to a flow](https://help.klaviyo.com/hc/en-us/articles/360035861011)
- Shortener: paste a URL and leave **Automatically shorten links** checked. Three forms: default `klv3.io/...`, branded Klaviyo subdomain (`jblck.klv3.io`, paid SMS plans), branded custom domain (`sms.example.com`). Custom domain is required for Universal Links and App Links. Short links “stop redirecting 90 days after the message is sent,” except compliance links such as unsubscribe. — [SMS vs WhatsApp shortened links](https://help.klaviyo.com/hc/en-us/articles/17649677926299); [Branded shortened link](https://help.klaviyo.com/hc/en-us/articles/17649597637147)
- Personalization tags work in SMS/MMS, including `{{ first_name|default:'friend' }}` style. Estimated character count is not exact when links or variables are present; first name is estimated as 6 characters in the example. — [SMS vs MMS](https://help.klaviyo.com/hc/en-us/articles/360041075091); [Message personalization reference](https://help.klaviyo.com/hc/en-us/articles/4408802648731)
- Preview: in-editor preview for a profile and country. Preview & test. Flow options differ for list/segment, date, and metric triggers (same pattern as email). — [Guide to crafting SMS and MMS](https://help.klaviyo.com/hc/en-us/articles/360035661191)
- MMS starts as SMS until media is added. Media types named: images, dynamic images, GIFs, virtual contact cards. One media file. Cannot reposition the image; iOS and Android can render it differently. File must be under 600 KB or carriers may compress it. — [SMS vs MMS](https://help.klaviyo.com/hc/en-us/articles/360041075091); [MMS image and GIF best practices](https://help.klaviyo.com/hc/en-us/articles/360041074911)
- MMS sending numbers: US toll-free and short codes, Canadian toll-free, Australian long codes. Not Canadian short codes or Australian branded sender IDs. If the number cannot send MMS, a dynamic image is dropped and the text still sends. Consent for SMS covers MMS. — [SMS vs MMS](https://help.klaviyo.com/hc/en-us/articles/360041075091); [Dynamic image in a text message](https://help.klaviyo.com/hc/en-us/articles/1260806102230)
- Character limits from the RCS comparison table (Mar 11, 2026): SMS 160, or 70 with non-GSM characters such as emoji; MMS 1,600, or 1,000 with non-GSM. The crafting guide’s best practice is “under 153 characters” because of header overhead, and MMS “up to 1600 characters.” — [RCS vs SMS vs MMS](https://help.klaviyo.com/hc/en-us/articles/46633303354907); [Guide to crafting SMS and MMS](https://help.klaviyo.com/hc/en-us/articles/360035661191)
- Formats: PNG, JPEG, GIF are agreed. **Conflict:** the crafting guide and its localized versions say you can upload WebP and Klaviyo converts it to PNG. The MMS best-practices article says “Other file types (including MP4 and WebP) are not available” and carriers may refuse WebP. MP4 is unsupported on both. — [Guide to crafting SMS and MMS](https://help.klaviyo.com/hc/en-us/articles/360035661191); [MMS best practices](https://help.klaviyo.com/hc/en-us/articles/360041074911)
- Dynamic image: one per MMS. Add image > Dynamic Image tab. Example uses a catalog tag around `catalog_item.featured_image.thumbnail.src` with the event’s product id. “Do not copy them from email templates” without checking the integration’s variable shape. — [How to add a dynamic image](https://help.klaviyo.com/hc/en-us/articles/1260806102230)
- Virtual contact card: enable under Settings > SMS, then in a flow SMS click Add Media > Virtual Contact Card. Converts the message to MMS. “Only accepted in the United States, Canada, and Australia.” Uses more credits. “You cannot add past profiles to flows that contain a virtual contact card.” Preview shows the organization initial, not the logo, even if a logo is set. — [How to add a virtual contact card](https://help.klaviyo.com/hc/en-us/articles/8219838827931)
- One coupon code per SMS. Same code is reused if email and SMS in a flow reference the same coupon. — [SMS coupon article](https://help.klaviyo.com/hc/en-us/articles/360044863132)
- **RCS is shipped, not a rumor, but it is opt-in per country.** After an RCS agent is activated, “RCS becomes the default message format for all text messages in the countries where you have an active agent.” Create an SMS campaign; the editor has an RCS message tab and an automatic SMS/MMS fallback. Rich messages can include “text, media, and interactive elements” in campaigns and flows. Setup is Settings > Text message > RCS: brand name, logo 224×224 JPG max 90KB, cover 1440×448 JPG max 200KB, color, description, US use case, phone or email, website, privacy policy, terms. — [Getting started with RCS](https://help.klaviyo.com/hc/en-us/articles/41066240307483); [How to create an RCS campaign](https://help.klaviyo.com/hc/en-us/articles/41072420801819); [How to set up RCS](https://help.klaviyo.com/hc/en-us/articles/46581422667035); [RCS help section](https://help.klaviyo.com/hc/en-us/sections/41065230525083)
- Capability table: Basic RCS is 160 characters, no media, “partial” quick actions in the US only. Single RCS is 3,072 characters text-only or 2,000 with media, one file up to 100 MB, and “cards, buttons, quick actions.” Read receipts and encryption on RCS, not on SMS/MMS. Click tracking on RCS is native; on SMS/MMS it is “via shortened links.” Location sharing: “not yet supported in Klaviyo.” Payment and app integrations: “not yet supported in Klaviyo.” — [RCS vs SMS vs MMS](https://help.klaviyo.com/hc/en-us/articles/46633303354907) (updated Mar 11, 2026)
- “Contact cards are a specific MMS message type and therefore not supported in RCS.” Tapping the RCS profile image opens an agent contact page. “You cannot save an RCS agent as a contact” in the FAQ, while another sentence says the ability to save “depends on a user’s mobile device and messaging app.” Deactivating RCS (currently via Support) falls everything back to SMS. — [Getting started with RCS](https://help.klaviyo.com/hc/en-us/articles/41066240307483)
- RCS fallback: profiles that cannot receive RCS get the SMS or MMS version. Fallback can be edited separately (strip emoji, fit one segment, remove media). — [How to create an RCS campaign](https://help.klaviyo.com/hc/en-us/articles/41072420801819)

### Inferences
- For a Shopify email-suite gap analysis, SMS parity is: text, variables, one tracked short link, branded domain, MMS image/GIF, dynamic product image, contact card, unique coupon, and country limits. RCS is a 2026 channel on top, not part of the email editor.

## Which of these are generally available vs beta or an add-on?

### Takeaway
The drag-and-drop blocks, sections, show/hide, Django tags, Shopify product feeds, Shopify unique coupons, UTM, and click tracking are documented as standard product behavior, not beta. Paid-account gates that were explicit: inbox testing, and branded SMS short links (paid SMS). Klaviyo Reviews is required for the review-quote block. Customer Hub and Marketing Analytics are separate products; they are not required to build a Shopify email. AMP needs an application. RCS needs an approved agent per country. Custom objects and predictive profile fields are exposed in templates, but the plan that unlocks them was not confirmed on the pages read.
